// Dubu36 keymap: the source of truth for the generated ZMK and QMK keymaps.
//
// Every `overlay` and `layer` block is a grid of the 36 keys: three rows of ten
// keys, then the six thumb keys. Each whitespace separated cell is one key:
//
//   LABEL             tap only
//   TAP/HOLD          taps TAP, holds HOLD (a modifier or a layer)
//   TAP/HOLD:FLAVOR   ... using an explicit hold-tap flavor
//   LABEL/LABEL       one-shot modifier/layer on tap, momentary on hold
//   _                 nothing: a blank key, or "no hold" when used as the hold
//
// FLAVOR decides how a hold-tap tells a tap from a hold. It is tp
// (tap-preferred), which is the default and suits the home-row, or hp
// (hold-preferred), for keys that should shift as soon as another key
// goes down. One-shot keys take no flavor.
// The behaviors these map to are defined in keymap_generator/zmk_template.dtsi.
//
// A layer inherits the holds of every overlay listed after its name, unless the
// cell defines its own hold. Use `LABEL/_` to drop an inherited hold.
// `layer name + MOD` holds MOD the whole time that layer is held. The
// modifier goes down when the hold is decided and stays down until the
// hold key is released, so every key on the layer is sent with it.
//
// Labels that clash with the `/`, `:` or `_` syntax are escaped with a
// backslash: `\/`, `\:`, `\_`, and `\\` for the backslash key itself.

// Modifiers used primarily in shortcuts, mapped to the home-row. The modifiers
// and layer shifts used in fluent writing live on the thumb keys instead, to
// reduce issues with hold-tap timing.
// Pinky to index, mirrored on the right: A shift, R control, S option,
// T command. The inner index (D and H) is a plain tap.
overlay homerow
  _      _      _      _      _          _      _      _      _      _
  shft   ctrl   alt    cmd    _          _      cmd    alt    ctrl   shft
  _      _      _      _      _          _      _      _      _      _
                _      _      _          _      _      _

// Colemak, with special characters remapped to prioritize commonly used
// characters in day-to-day writing.
// X holds Fn (tap-preferred, same as the home row). C holds the app
// layer and V the OS layer; the right hand mirrors those holds onto
// . , and M. App holds right command and OS holds right option.
layer default: homerow
  Q      W      F      P      G          J      L      U      Y      *
  A      R      S      T      D          H      N      E      I      O
  Z/adj  X/fn   C/app  V/os   B          K      M/os   ,/app  ./fn   '/adj
          BKSP shft/shft lwr/lwr         rse/rse  SPC      _

  _      4      5      6      _          FWD    LEFT    DOWN      RIGHT   BCK
  0      1      2      3      _          TAB_L  HYP_[   HYP_\\    HYP_]   TAB_R

// App shortcuts, held from C and from comma. Right command is down for

// Chords, written as `KEY KEY -> RESULT`, where the two keys are the labels of
// the keys pressed together on the default layer.
//
// The pair has to be one that never gets typed back to back, or the chord
// fires by accident mid-word. A home-row pair like S+T would catch every `st`.
// W+F (Esc) is a top-row ring/middle pair Colemak does not roll. U+Y (Enter)
// is the matching pair on the right; it does occur in rolls such as "buy"
// and "guy", so that chord can fire inside those words.
// Esc and Enter also sit on rse (outer and inner left thumbs), so one-shot or
// held raise plus that key types them without a chord. Esc stays on lwr as well.
combos
  W F -> ESC
  U Y -> RET
