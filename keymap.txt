// Source of truth for the generated ZMK and QMK keymaps.
//
// Each overlay/layer is 36 keys: three rows of 10, then 6 thumbs. Cells:
//
//   LABEL             tap only
//   TAP/HOLD          tap TAP, hold HOLD
//   TAP/HOLD:FLAVOR   ...with an explicit hold-tap flavor
//   LABEL/LABEL       one-shot on tap, momentary on hold
//   _                 blank, or "no hold" on the hold side
//
// FLAVOR is tp (tap-preferred, default, home-row) or hp (hold-preferred,
// thumbs). One-shot keys take none. Behaviors live in
// keymap_generator/zmk_template.dtsi.
//
// A layer inherits holds from overlays listed after its name. LABEL/_ drops one.
// Escape /, :, _ and \ in a label with a backslash.

// Shortcut modifiers on the home row. Writing mods and layer shifts sit on
// the thumbs, where hold-tap timing is less of a fight.
overlay homerow
  _      _      _      _      _          _      _      _      _      _
  hyp    shft   alt    cmd    ctrl       ctrl   cmd    alt    shft   hyp
  _      _      _      _      _          _      _      _      _      _
                _      _      _          _      _      _
